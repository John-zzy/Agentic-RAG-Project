# Benchmark Security Policy

## Remote Access

- Remote access must use MFA for every sign-in.
- Shared accounts are not allowed for employees or contractors.
- Company data may only be accessed from managed devices with disk encryption enabled.

## Device Handling

- Lost or stolen managed devices must be reported to the security team immediately.
- Personal devices are not approved for storing company data.

## Incident Reporting

- Suspicious login activity must be reported to the security team within one hour.
- The report should include the account name, approximate time, location, and any unusual prompt.
